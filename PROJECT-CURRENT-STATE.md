## 1. Project Overview

### Project Identity

- **Project name / product name:** Tawasul Academy (Arabic: تواصل). **CONFIRMED:** `package.json` (`"name": "tawasul"`), docs, and Nuxt app metadata.
- **Type:** Arabic-first web platform for psychological, educational, and family counseling consultations, delivered online and in clinic. **CONFIRMED:** `pages/index.vue`, PRDs, PROJECT_SUMMARY.
- **Base locale:** Arabic, `dir="rtl"`, `lang="ar"`, IBM Plex Sans Arabic + Inter. **CONFIRMED:** `nuxt.config.ts`.
- **Version state described by docs:** 1.0 MVP as-built (September 2026); current repository additionally contains v1.1/hardening work and recent admin fixes. **PARTIALLY VERIFIED:** Docs are internally consistent, but repository dates and migration state cannot fully confirm current calendar state.

### Business Idea and Target Audience

- **Business idea:** Patients self-register, select a slot from a global admin-controlled schedule, pay online (Paymob primary, Stripe alternative, dev mock fallback), and join a LiveKit video session; admins triage pending bookings and assign doctors; doctors manage calendars/profile/notes. **CONFIRMED:** PRD-ASBUILT and routes/API.
- **Target audience:** Arabic-speaking patients needing mental health/family/tutoring counseling, licensed doctors/therapists, and platform staff/admins. **CONFIRMED:** docs + homepage copy.
- **Monetization:** Session pricing from `Settings.sessionPricePerHour` multiplied by session duration. Online bookings create payments; in-clinic bookings skip payment and are amount 0. Payment gateway switch available. **CONFIRMED:** booking create and payment initiate APIs. No subscription or other billing model is implemented. **MISSING:** refunds automation beyond manual gateway handling; doctor earnings.

- **Permission resources:** `APPOINTMENTS`, `PATIENTS`, `DOCTORS`, `PAYMENTS`, `SETTINGS`, `STAFF`. **CONFIRMED:** Prisma schema.
- **Permission actions:** `CREATE`, `READ`, `UPDATE`, `DELETE`. **CONFIRMED:** Prisma schema.
- **RBAC rule:** Permissions are re-queried from PostgreSQL on every protected server request via `permission.findMany`; they are not cached in JWT. **CONFIRMED:** `server/utils/permissions.ts`.
- **Seed admin:** created by `prisma/seed.ts` as `STAFF` with 14 core permissions (notably `DOCTORS:DELETE`, `PAYMENTS`, `SETTINGS:UPDATE`) plus all 7 active admin schedule days. **CONFIRMED:** seed file.

### Module/Architectural Pattern

- **Modular monolith:** feature modules under `modules/{auth,booking,payment,patient,doctor,admin,session}` each own pages/components/composables/server API scan dirs. **CONFIRMED:** `nuxt.config.ts`, module `index.ts`.
- **Global pages/layouts/middleware/composables:** under `pages`, `layouts`, `middleware`, `composables`, `server`.
- **Routing registration:** `pages:extend` recursively scans each module `pages` directory. **CONFIRMED:** `nuxt.config.ts`.
- **Data flow:** Browser -> Nitro REST API -> Zod validation -> Prisma/PostgreSQL and external services. Client-side route middleware is UX gating; server middleware/API remains final boundary. **CONFIRMED:** code.
- **Real-time session:** Client LiveKit SDK connects directly to LiveKit SFU using server-generated short-lived tokens. **CONFIRMED:** `screen/utils/livekit-token.ts` and composables.
